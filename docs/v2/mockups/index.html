Brew Bowl v2 mockups

113 pages. These are pictures, not the real app, and every name and number is made up. Player is someone who only plays. Admin shows the admin tools and puts an Admin tab on the player pages, as it would for an admin who also plays. All shows every page, with that Admin tab too. Search, or open and close a group. On a phone, or in a browser window about 390px wide, the pages look the way they will in someone's hand.
